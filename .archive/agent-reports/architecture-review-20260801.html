Problem. The generator→renderer handoff is an implicit filesystem contract: 16 gitignored JSON files imported raw at module load; a missing or stale snapshot renders empty pages silently and data tests collect 0 cases — the F1 failure class.

Solution. One deep snapshot module — the schema.mjs validation already written is enforced at load behind one typed interface; the shims collapse into it; pages cross one seam.

Wins

  • stale snapshot fails loudly at load
  • delete ~13 shallow shims
  • locality: bugs concentrate in one module
